# Polish CNC Menu

1. Inspect the rendered menu at every target viewport before editing.
2. Preserve all navigation content and route semantics.
3. Build desktop composition on a 12-column grid: family rail, category field, technical preview.
4. Use scale, index, rules, datum marks, and restrained metallic surfaces to create hierarchy.
5. Keep touch layouts direct: sticky family rail, one-open category disclosure, persistent conversion action.
6. Treat focus and hover as equal visual states; never hide required information behind hover.
7. Use only project fonts, icons, and original CSS graphics.
8. Validate contrast, 320px width, short landscape, long Turkish labels, and content overflow.

Read [references/art-direction.md](references/art-direction.md) before choosing tokens or approving a composition.
