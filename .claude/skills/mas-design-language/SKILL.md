# MAS TECHNIC Design Language

- Derive public UI from the current TechnicalLanding, not generic SaaS/shadcn aesthetics.
- Visual DNA: graphite/charcoal industrial field, warm technical-paper surfaces, restrained bronze editorial accent, semantic status green only, hairline rules, engineering-sheet precision.
- Typography hierarchy: geometric grotesk for primary interface/body, editorial serif accent for selective expressive headings, monospace only for technical data, labels, measurements, codes, tables, units, indexes.
- Avoid generic rounded cards, glow/neon/cyberpunk, glassmorphism, decorative gradients, excessive pills, random icon-card grids, stock-corporate composition.
- Reuse the rail/index, technical rules, evidence/document motifs, metrology language, and measured negative space.
- Inner pages must share the same system, not merely the same colors/fonts. Carry grid logic, rail logic, type hierarchy, border/rule system, motion grammar, proof language, menu, transitions, and footer.
- Preserve visual hierarchy: not every band is a climax. Create quiet evidence bands between major moments.
- Prefer proof over claims and technical specificity over marketing adjectives.
- Do not expose company scale merely because it is known. Position through capability, process discipline, measurement, traceability, and evidence.
