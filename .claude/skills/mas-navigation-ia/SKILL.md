# MAS TECHNIC Navigation & IA

- One public global navigation system. Eliminate competing public header languages (`TechnicalHeader` vs generic/fullscreen variants) through consolidation.
- Menu must feel like the TechnicalLanding world: technical grid, numbered/indexed navigation, engineering/editorial typography, restrained motion.
- Group routes meaningfully: capabilities/services, industries, quality/resources/case studies, company/contact; RFQ is a strong but coherent CTA.
- Landing anchors and full-page routes must be distinguishable.
- Every public service/sector/important content page must be reachable; no orphan pages or dead-end flows.
- Active route and active landing-section state must be clear without noisy decoration.
- Fullscreen/open-state behavior: correct focus trap, ESC close, focus restore, scroll lock, keyboard navigation, reduced-motion fallback, no layout shift.
- Mobile is the same concept adapted, not a cheap hamburger afterthought.
- Avoid decorative sound/theme/cursor controls unless they serve a real product/brand function.
- Dev/legacy/test routes must not pollute production navigation.
