# 00 · Project Brief — Mas Technic

## Şirket Kimliği

**Şirket:** Mas Technic  
**Sektör:** CNC Hassas İmalat, Yüzey İşlemleri, Endüstriyel Üretim  
**Konum:** İstanbul, Türkiye  
**Ölçek:** Orta ölçekli B2B imalat, üst segment müşteri profili  
**Dil:** Türkçe (tüm UI ve içerik)

## Vizyon

Türkiye'nin CNC imalat sektöründe dijital deneyim standartlarını yeniden belirlemek.  
Hedef: Sektörün en premium web varlığı — rakip siteler kurumsal katalog mantığıyla çalışırken Mas Technic müşteriye sinematik bir deneyim sunuyor.

## Hedef Persona

**Birincil:** B2B mühendis / satın alma sorumlusu  
- 30-50 yaş, teknik arka plan  
- Referans veya Google aramadan geliyor  
- Kalite kanıtı arıyor (sertifikalar, tolerans değerleri, proje portföyü)  
- Karar verici ya da karar sürecine giriyor  
- Mobilde inceler, masaüstünde teklif verir

**İkincil:** İşletme sahibi / genel müdür  
- Stratejik ortaklık arayan  
- "Bu firmaya güvenebilir miyim?" sorusunu soran  
- Kurumsal güven sinyallerine duyarlı

## Paydaşlar

| Rol | Sorumluluk |
|-----|-----------|
| Mas Technic yönetimi | İçerik onayı, iş kararları |
| Claude Code (AI) | Kod geliştirme, dokümantasyon |
| Müşteriler | RFQ, portal kullanımı |
| Admin / staff | Sipariş yönetimi, müşteri iletişimi |

## Proje Kapsamı

### İçinde
- Landing page (awwwards hedefli)
- Müşteri portalı (teklif, sipariş, üretim takibi)
- Yönetim paneli (15 modül)
- RFQ akışı (CAD upload + 3D viewer)
- Blog (6 makale + kategori)
- Malzeme kataloğu (500+ materyal)
- Hizmet sayfaları (50+)
- AI chatbot (Gemini 2.0 Flash)

### Dışında
- Mobil uygulama
- E-ticaret / ödeme altyapısı
- İngilizce içerik (şimdilik)
- CMS entegrasyonu

## Kısıtlar

- **Teknoloji:** Vite+React, Supabase backend — Next.js/SSR yok
- **İçerik:** Türkçe — SEO Türkçe hedefli
- **Platform:** Lovable.dev deploy → Claude Code geliştirme
- **Budget:** Premium görünüm, pragmatik geliştirme — overengineering yok
- **Süre:** Awwwards Honorable Mention için 3-6 ay polish gerekiyor

## Rekabetçi Konum

Türk imalat sektöründe web kalitesi genellikle düşük (statik HTML, eski tasarım).  
Mas Technic'in avantajı: sinematik animasyon + güçlü teknik içerik kombinasyonu.  
Doğrudan awwwards rakibi değil; sektör içinde kategorik üstünlük hedefleniyor.
