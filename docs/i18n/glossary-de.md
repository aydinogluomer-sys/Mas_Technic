# MAS TECHNIC — German translation rules and glossary (L3)

Audience: German-speaking purchasing and engineering staff at industrial
customers (DACH). Register: formal, precise, technical B2B. Address the reader
with "Sie". No marketing superlatives that the Turkish/English source does not
contain. Never add claims, numbers, certifications or promises.

## Hard rules (a checker enforces these)
1. Keep every `{{placeholder}}` exactly as in the source (same names, same count).
2. Never change a number. Write decimals with the German comma in running text
   and labels: `±0.01 mm` → `±0,01 mm`, `Ra 0.8` → `Ra 0,8`, `120.00 × 72.00`
   → `120,00 × 72,00`. Integers stay as they are. Do not add or drop numbers.
3. No Turkish letters (ğ ş ı İ ç ö ü as Turkish words) may remain, except proper
   names: İzmir, Çiğli, Ataşehir, MAS TECHNIC, Mas Technic.
4. Keep case style: an ALL-CAPS source stays ALL CAPS in German (use ß → SS in
   caps). Title case for headings follows German rules (nouns capitalised,
   otherwise sentence case).
5. Keep symbols and separators: `·`, `—`, `→`, `×`, `±`, `Ø`, `µm`, `mm`, `°C`.
   Use German quotation marks „…“ where the source has quotes.
6. Keep brand/product names unchanged: MAS TECHNIC, Mas Technic, NEXUS,
   PRECISION CNC, ISO 9001:2015, ISO 14001, EN, DIN, ASTM, AISI, CAD/CAM file
   format names (STEP, IGES, STL, DXF, PDF, X_T…).
7. Keep it as short as the source; UI labels must fit the same space. Prefer
   compact German forms (e.g. "Angebot anfordern", not "Fordern Sie ein Angebot an").
8. Output German only — no comments, no alternatives, no English left over
   (except the fixed names above and standard technical abbreviations).
