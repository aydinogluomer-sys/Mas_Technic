## Technique selection

Accepted: current Lenis desktop momentum (native mobile retained), intersection-gated image counter-drift, masked type, geometry-safe registration lines, native button dimension selection, selected NEXUS panel handoff, focus-equivalent document/index inspection feedback.

Rejected: global velocity skew/kinetic data text (reading cost); mandatory sound (no buyer task); persistent canvas/FBO/bloom/displacement (no appropriate new asset or measured benefit); DRACO/progressive mesh loading (no new mesh payload); magnetic fields/cursor changes (existing cursor sufficient). Existing Three/CAD viewer remains functional in RFQ, with no change to rendering/upload authority. Hero image is a photograph with exact SVG dimension leaders, so camera/raycast movement would detach the leaders from their source geometry; DOM selection is the truthful equivalent here.
