## Changed

- **`Footer.tsx`** (488 → 157 satır):
  - **RC-1/RC-3 (Spacer ölçümü):** `offsetHeight` → `scrollHeight` geçişi. `ResizeObserver` + `document.fonts.ready.then(updateHeight)` + `requestAnimationFrame` wrapper ile font swap / lazy image sonrası reflow yakalanıyor. Layout thrashing önlemi: `lastH` cache + diff check.
  - **RC-4 (Z-index):** Footer reveal variant `zIndex: 30` (önceden 0) → `finalCta` (z=24) üzerinde garanti.
  - **RC-8 (Bottom bar overflow):** `flex-col lg:flex-row` + `flex-wrap` + `lg:pr-20` → 1280px altında copyright/legal linkler kesintisiz, sağ alt floating chat butonu için 80px rezerv.
  - **RC-9 (Mobile horizontal overflow):** Watermark `clamp(40px, 12vw, 160px)` + `max-w-full overflow-hidden`; newsletter form container `min-w-0`.
- **Memory:** `mem://design/footer-reveal-pattern` v3.4/v3.5 kuralları ile güncellendi (scrollHeight, fonts.ready, z=30, lg:pr-20 chat rezervi, RC-9 watermark guard).
